# Install (Local)

If your agent runtime supports loading skills from the user skills directory, copy this folder into your skills path:

- Source: `diamond-booking/skills/ultimate-saas-booking-skill-v5`
- Destination: `~/.agents/skills/ultimate-saas-booking-skill-v5`

After copying, restart the agent/runtime so it discovers the new skill.

If you prefer creating a first-class package-managed skill, use the Skills CLI to initialize a skill repository and move `SKILL.md` into it.
